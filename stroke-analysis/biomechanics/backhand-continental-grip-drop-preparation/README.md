# Serve & Backhand Biomechanics: Continental Grip Behind Handle & Hand-Below-Ball Preparation

This directory contains research on the shared anatomical mechanics of the Continental Grip (Bevel 2) between the serve and the one-handed backhand, as well as the vertical hand-below-ball preparation dynamic.

## Key Points
1. **Hand Placed Behind the Handle (Bevel 2):** Unlocks forearm pronation on the serve and provides skeletal shock absorption behind the 1HBH collision.
2. **Hand Pulled 15–20 cm Below Ball Level:** Keeps the racket head elevated, creating a steep, gravity-driven low-to-high swing ramp that produces heavy Magnus topspin.
