# Tennis Biomechanics: Plane of Swing vs Stance vs Shot Type

Biomechanical analysis of directional control in tennis, evaluating how footwork stance alignment (Open vs Closed) predetermines the swing plane for Cross-Court (C-C) and Down-The-Line (DTL) groundstrokes.

## Key Themes:
1. **Core Axiom:** "Open for Cross-Court, Closed for Down-The-Line" (Muốn chéo thì mở, muốn dọc thì đóng).
2. **Four-Quadrant Matrix:**
   * Backhand - Open Stance (C-C): Left-to-right curved swing plane.
   * Forehand - Open Stance (C-C): Right-to-left curved topspin arc.
   * Backhand - Closed Stance (DTL): Linear baseline-to-net driving plane.
   * Forehand - Closed Stance (DTL): Linear back-to-front down-the-line corridor.
3. **Contact Point Timing:** Open requires early contact in front; Closed requires contact adjacent to lead hip.
4. **The 45° Angle:** The optimal golden ratio for semi-open stances.
