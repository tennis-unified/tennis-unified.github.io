## Overview

This coaching dossier and technical research package covers:
1. **Force Vector Dynamics:** Why linear displacement along straight lines imposes zero transverse acceleration ($a = 0$) and a kinetic dead-stop, whereas curvilinear Figure-8 geometry harnesses continuous centripetal acceleration ($F_c = \frac{m \cdot v^2}{r}$).
2. **The Highway On-Ramp Analogy:** How entering a curve smoothly elevates angular velocity, allowing stored elastic energy to fling the ball forward with maximum Racquet Head Speed (RHS).
3. **The 5 Kinematic Phases:**
   - Phase 1: Unit Turn ($45^\circ - 60^\circ$ torso coil, both hands on racket).
   - Phase 2: Gravitational Drop (low elbow $10-15\text{ cm}$ from ribs, supple wrist).
   - Phase 3: Lag & Snap (pelvic lead, stretch-shortening cycle torque).
   - Phase 4: Ball Impact ($30-40\text{ cm}$ in front of lead hip, $80^\circ - 85^\circ$ micro-closed face).
   - Phase 5: Follow-Through (release all energy into natural windshield wiper finish).
4. **Interactive Analysis Suite:** Embedded standalone React coaching web application (`interactive.html`) featuring real-time 3D vector visualizations, interactive timeline controls, physics calculators, and ZIP export tools.
5. **Video Breakdown & Archival Notes:** Federer 8 motion video analysis and original high-resolution coaching notes.
