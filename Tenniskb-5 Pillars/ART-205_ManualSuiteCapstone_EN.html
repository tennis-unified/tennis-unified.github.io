ART-205: Master Plan — The Manual Suite Capstone (The "Operating System")

Executive Summary

Articles 191-194 produced four master documents: Athlete Career Plan (CEO), Coach Program Plan (COO), Academy System Plan (Factory), Parent Support Plan (Shareholders). This capstone integrates them into a single Unified Operating System — the "Manual Suite" — with version control, governance, interlocking reviews, and the "Single Source of Truth" architecture for the 5-Pillar high-performance enterprise.

The Manual Suite Architecture: One System, Four Manuals

The Integration Principle

  • Athlete Career Plan (ART-191): The Strategy (Where & Why).
  • Coach Program Plan (ART-192): The Operations (What & How).
  • Academy System Plan (ART-193): The Infrastructure (Environment & Capacity).
  • Parent Support Plan (ART-194): The Governance (Boundaries & Investment).

Rule: No manual exists in isolation. Every change in one triggers a review in the others. Version Control is Mandatory.

The Unified Governance Model: "The Board"

Composition

  1. Athlete (CEO) — Vision, Values, Final Authority.
  2. Head Coach / Program Director (COO) — Operations, Delivery, Quality.
  3. Technical Director (Academy) — Infrastructure, Curriculum, Coach Development.
  4. Parent Representative(s) — Investment, Welfare, Boundary Enforcement.
  5. Independent Welfare Officer — Safeguarding, Ethics, Athlete Voice.
  6. Agent / Manager (Optional) — Commercial, Schedule, Legal.
  7. Medical Director (Advisory) — Health Autonomy, RTP Veto.

Meeting Cadence (The "Heartbeat")

Cadence Meeting Chair Required Attendees Key Decisions
Weekly Performance Stand-Up COO CEO, COO Weekly Theme. Load Adjust. Red Flags.
Monthly Operations Review COO CEO, COO, TD, Parent Rep KPI Trends. Schedule Changes. Protocol Updates.
Quarterly Strategic Board Meeting CEO All Board Members Assessment Results. Manual Updates. Budget. Team Changes. Risk Review.
Annual Annual General Meeting Chair All + Agent + Medical Dir Vision Reset. Contract Renewals. Financial Audit. Manual Suite Version Bump.

The Version Control System: "Git for Tennis"

Repository Structure

├── v1.0_YYYY/                 # Annual Major Version
│   ├── 191_Athlete_Career_Plan.md
│   ├── 192_Coach_Program_Plan.md

│   └── 195_Manual_Suite_Index.md
├── v1.1_Q2_YYYY/              # Quarterly Minor Version
│   └── (changed files only)
├── Working_Drafts/            # In-progress edits
└── Archive/                   # Superseded versions

Change Management Protocol

  1. Proposal: Any Board Member submits "Change Request" (CR) with Rationale, Impact Analysis, Affected Manuals.
  2. Impact Analysis: COO + TD assess Technical, Operational, Financial, Welfare impact.
  3. Review Window: 7 Days for Board Comment.
  4. Decision: CEO Approves / Board Consensus (Major Changes).
  5. Implementation: COO updates Manuals. Version Bump (Major.Minor.Patch).
  6. Communication: Change Log Distributed. "What Changed" Summary to Athlete/Parents.
  7. Archive: Previous Version Archived. Read-Only.

Versioning Scheme

  • Major (vX.0): Annual AGM. Vision/Strategy Shift. New Manual Structure.
  • Minor (vX.Y): Quarterly Board. New Mesocycle. Coach Change. Major Protocol Update.
  • Patch (vX.Y.Z): Weekly/Monthly. KPI Target Tweak. Drill Swap. Schedule Adjust.

The "Single Source of Truth" (SSOT) Dashboard

Master KPI Dashboard (Shared Across All Manuals)

  • Athlete: 5-Pillar KPIs, Ranking, Tournament Results, Injury Days, HRV Baseline, Sleep, Wellness.
  • Coach: Session Architecture Compliance, Q:I Ratio, Feedback Fading, Athlete Talk Time, Supervision Completion, Coach HRV.
  • Academy: Retention, Stage-Gate Attainment, Coach Audit Scores, Parent NPS, Injury Rate, Safeguarding, Financial Surplus.
  • Parents: Education Attendance, Board Meeting Compliance, Lane Violations, Match Day Compliance, Car Ride Incidents, Budget Variance, Stress Score.

The Continuous Improvement Loop (The "Kaizen")

Quarterly Kaizen Cycle

  1. Measure: Pull SSOT Dashboard Data.
  2. Analyze: Board Meeting — Root Cause Analysis on Misses.
  3. Improve: Approve Change Requests. Update Manuals.
  4. Control: Monitor New KPIs for 4 Weeks. Standardize or Revert.

Annual "Manual Suite Retrospective"

  • Process: Full Board Offsite (2-3 Hours).
  • Agenda:
    1. Year in Review: Wins, Misses, Surprises.
    2. Manual Suite Health: Usability, Relevance, Completeness.
    3. Governance Effectiveness: Meeting Quality, Decision Speed, Conflict Resolution.
    4. Tooling: Dashboard UX, Version Control Friction, Communication Flow.
    5. Major Version Planning: v(X+1).0 Scope. Structural Changes.
  • Output: Signed Charter for Next Year. New Version Baseline.

The "Red Flag" System-Wide Triggers

  1. Any Manual > 30 Days Overdue for Quarterly Update.
  2. SSOT Dashboard Shows > 3 Red KPIs Simultaneously.
  3. Board Meeting Cancelled > 1 Consecutive Cycle.
  4. Version Control Conflict (Two Versions in Use).
  5. Safeguarding Incident in Any Domain.
  6. Athlete Voices Loss of Trust in System.

Practical Application: "The Constitution"

The Manual Suite is the Constitution of the 5-Pillar Enterprise. It is not four PDFs. It is a living, version-controlled, governance-backed operating system. The Athlete Career Plan sets the Destination. The Coach Program Plan drives the Vehicle. The Academy System Plan builds the Road. The Parent Support Plan fuels the Journey. The Manual Suite Capstone steers the convoy. One System. One Truth. One Version. One Team.
